# dreamtuesday.com

Landing page for Dream Tuesday, the company behind Mariah and Tray Brunner's work (Avori, Learn AI with Mariah, Bamboo Ave).

Plain static site, no build step. Everything Netlify publishes lives in `site/`, and a push to `main` deploys it.

- Page: `site/index.html`
- Styles: `site/css/site.css` (Avori's visual language: black/white, Neue Haas Display, hairlines)
- Hero photo: replace `site/assets/img/hero-wide.jpg` (desktop, 1452x817) and `site/assets/img/hero-tall.jpg` (phones, 4:5), keeping the same file names.

The old Vite/React app is in git history (commit b1cf5b6 and earlier).
